# Essential-task-management-by-AI

## Overview

将来目標と現在のタスクを結びつけ、
AIがタスクの価値や将来的な貢献を評価する
タスクマネジメントシステム。

## Features

1. 将来目標の入力
   - 大目標
   - 中目標
   - 小目標

2. 現在のタスクの入力

3. AIによるタスク評価
   - タスクの抽象化
   - 必要スキルの分析
   - 獲得できるスキルの分析
   - 将来目標との関連性の評価

4. AIによるフィードバック
   - 将来的な活用可能性
   - 目標への貢献度
   - 推奨行動と判断理由

## Tech Stack

- Python
- Streamlit
- LLM API
- Git / GitHub
